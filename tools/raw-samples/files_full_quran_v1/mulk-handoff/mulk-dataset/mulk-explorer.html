What this prototype demonstrates

Loaded, not embedded

Fetches data/mulk.json at runtime. The UI adapts to whatever schema the file has — no hand-maintained copy.

Multi-level view

Toggle word / phrase / clause colouring. Word colours use the real cat field (V, N, P, PRON, REL, NEG, CONJ, REM, CIRC…).

Bilingual, from the file

Per-phrase and per-word glosses come from translations and gloss_en/gloss_bn. Ayah-level reference_translations (Sahih + Zakaria) shown in the Refs tab.

Root highlighting

Click any word → every word with the same root is highlighted across all 30 ayahs.

Phrase grouping

Group by Arabic text_norm (repeated Arabic phrases) or by translation_keys.en (same English phrase). Both indexes are built at load.

Consistency

Quality tab checks: same Arabic phrase → one translation key (0 conflicts in this file). Also verifies phrase and clause tiling.

Mutashabihat

Each ayah's mutashabihat (phrase repetition across the Qur'an) and matching_ayah are surfaced as clickable references.

Morphology, complete

Tooltip shows root, lemma, stem, qac_lemma, pos, cat, prefix_tags, definite, suffix_pron, features, and waqf_mark.

Waqf-aware

Waqf marks displayed as superscript; phrases that end on a waqf are counted in the Quality tab.

Frequency

Top roots, top phrase keys, top clause keys, and length histograms — all derived from the loaded data.

No build step

Single HTML file. Point it at any directory containing data/mulk.json, or pick the file manually.

Scales

Swap data/mulk.json for a combined surah dump and the same UI works — no code change.
