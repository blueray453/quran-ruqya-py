KEY COUNTING NOTES
- QUL word-by-word vocabulary: 77,432 word entries; 21,294 distinct surface forms.
- Surface vocabulary percentages use 77,432 word entries as denominator.
- QUL lemma mappings cover 72,510 occurrences; QUL root mappings cover 50,298.
- QAC verb morphology: 19,356 verb-stem occurrences.
- QAC syntax: 103,781 dependency instances after excluding tree metadata labels
  root and NonRel, retaining link as a PP-attachment relationship.
- MASAQ: 110,886 observed syntactic-role annotations.
- These populations are not interchangeable and their percentages must not be
  added together. Cross-source token alignment is not yet token-perfect.

LIMITATIONS
- Surface-form coverage is lexical exposure, not comprehension.
- Sarf reports distinguish verb form, aspect, voice, mood and feature bundles.
  The dimensions overlap and must be interpreted separately.
- Nahw dependency relations (QAC) and syntactic-role annotations (MASAQ) are
  separate annotation systems.
- Complete integrated verse comprehension requires learner testing on unseen
  Quranic passages.
- Verify dataset and book licensing before commercial reuse.
