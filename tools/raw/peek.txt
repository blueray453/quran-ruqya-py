## How to get the JSON download link on any detail page

1. Open the category URL above.
2. Click the card for the specific resource.
3. On the detail page, find the **Download** section (or a dropdown next to the resource title).
4. Choose **JSON** (not SQLite). The button triggers a file download; the browser's download manager will show the actual URL if you right-click → Copy link address.
5. Save the file into `tools/raw/` with the exact filename from the table above (the script matches by name).

The QUL documentation confirms the pattern: open `https://qul.tarteel.ai/resources/recitation`, pick the card, and download JSON or SQLite. Same for script, translations, and metadata.

## One shortcut for the recitation files

If the browser download URLs are awkward to capture one by one, the recitation JSON is what `fetch_qul.py` uses to derive everything—including the audio CDN URLs. You can capture the recitation JSON once per reciter from the detail page, and the script does the rest (`audio_url` host → internal reciter ID → MP3 download). The five recitation files are the only ones where the exact filename includes the numeric suffix (`951`, `953`, etc.), so verify the filename matches what the script expects; if QUL has updated a resource and the suffix changed, just rename the downloaded file to match the table.
